### ⛏️ SVS 2日目（火曜日）：資源採集

**前日の夜に採集部隊を再出発させておくと、2日目開始後すぐに採集ポイントを獲得できます。**

**例：採集時間が約8時間30分の場合**
- 月曜深夜1時頃に再出発，火曜9時30分頃に帰還
- → **2日目開始後、すぐに1回分のポイントを獲得 👍**

### 🪖 SVS 4日目（木曜日）：訓練昇格

**訓練時間に合わせて、前日の夜にもう一度訓練を開始しておくと、4日目開始後すぐに訓練を完了できます。**

**例：訓練時間を調整する場合**
- 水曜夜に訓練を再開，木曜9時以降に訓練完了 
- → **4日目開始後、すぐにポイントを獲得 👍**

> 💡 **3000ダイヤを使用する場合**
> 訓練開始時間を**3倍前倒し**にすることができます。
> → 木曜9時の4日目開始後に、**訓練を3回分すぐに完了**させることができます。👍
