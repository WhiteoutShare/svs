# 「SvS」

自分の所属するサーバー全体の総力を挙げて、マッチングした別のサーバーと勝敗を競い合う。

イベントの詳しい仕組みや流れは以下の通り。

## 主なフェーズの流れ

- **マッチングフェーズ**：対戦相手となる他のサーバーが決まる期間。

- **準備フェーズ**：日替わりのミッション（施設の強化や兵士の訓練など）をクリアし、サーバー全体の合計ポイントで競う期間。

- **戦争フェーズ**：敵のサーバーへ移動して都市を攻撃したり、中央の「太陽城（王城）」を奪い合ったりする戦闘期間。

## 勝敗と報酬のポイント

- **準備フェーズの重要性**：ここでの勝敗が、戦争フェーズでの展開やリスクに大きく影響します。
- **豪華な報酬**：勝利したサーバーは、特別なバフや報酬、サーバーを統率する役職の権限などを手に入れることができます。

# ①マッチメイキングフェーズ

マッチメイキングフェーズでは、イベントの詳細ルールや対戦相手の情報、SvSの開始時刻などが告知される。

同盟メンバーとルールを確認して、SvSに向けての動きを考えておく。

事前に動きを決めておくとで、SvS中の動きをスムーズに進められる。

---

# ②準備フェーズ

### フェーズの詳細

- ミッションクリアでポイントを獲得
- ポイント獲得で王国ボーナスを受け取れる
- 王国ボーナスを獲得する

準備フェーズでは、各フェーズごとに指定されたミッションをクリアすることで、個人ポイントと自身が所属している王国がポイントを獲得可能。

準備フェーズが終了した段階で、より多くポイントを得た王国が戦争フェーズにおける治癒ボーナスと徴兵収容量アップの王国ボーナスを得られるので、ミッションには積極的に挑戦する。

---

# ③戦争フェーズ

### フェーズの詳細

- クロス王国・王城決戦と戦争がある
- 準備フェーズのポイント獲得数で攻撃側が決定
- 戦争は準備フェーズの勝敗を問わずに敵王国を攻撃可能

### ⑴クロス王国・王城決戦

クロス王国・王城決戦では、準備フェーズでミッションを多くクリアした王国が攻撃側となり、相手の太陽城を攻撃する。

攻撃側の太陽城は保護状態になるため、攻撃を受けない。

### ⑵クロス王国・戦争

クロス王国・戦争では、準備フェーズの勝敗に関わらず相手を攻撃可能。

大溶鉱炉レベルの差が3以下の王国領主と戦った場合、敵軍を倒した際や自軍の兵士が負傷した際にポイントを獲得できる。

大溶鉱炉レベルの差は集結リーダーの大溶鉱炉レベルに準じるので、攻撃対象とレベルが近いメンバーが集結を発起するといい。

---

# ④戦地救急フェーズ

### フェーズの詳細

- 戦地救急フェーズは2日間
- 復活率は初期状態で30%
- 復活薬剤を使用すると最大+10%
- 同盟メンバーに救援要請すると最大+50%

戦地救急フェーズでは、戦争フェーズ中に死傷した兵士を復活できる。

復活率は基本が30%で、復活薬剤を使用すると+10%、同盟メンバーに救援要請して蘇生秘典を使用してもらうことで+50%、合計90%までの兵士を復活可能。


# ■シールドについて
- SVSでは、王城決戦の前後に相手国の領主が4471に来て、ポイント獲得のため都市を攻撃することがあります。 
- 特に、参加せずオフラインになる方は、都市攻撃を防ぐため24時間シールドの使用を推奨します。 
- 自分で被害を防ぐことで、限られた救済ポイントを必要な方へ回すことができます。
